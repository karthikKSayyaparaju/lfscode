Syllabus

  1. Print statements

    Send output to the console and combine strings and values.

    print("Hello, world!")
    • Print literals or variables; print("Hi", name) inserts a space for you.
    • Use f"" strings to embed expressions inline, e.g., f"2 + 2 = {2 + 2}".
    • Multiple arguments become space-separated in the output.

  2. If statements

    Branch logic with if, elif, and else.

    score = 82\nif score >= 80:\n    print("B or better")

  3. For loops

    Iterate over sequences or ranges to repeat work.

    for i in range(3):\n    print(i)

  4. While loops

    Repeat while a condition stays true; update the condition to avoid infinite loops.

    count = 0\nwhile count < 3:\n    print(count)\n    count += 1

  5. Functions

    Group logic into reusable blocks with parameters and return values.

    def greet(name):\n    return f"Hi {name}"\n\nprint(greet("Ada"))

  6. Lists

    Ordered collections you can append to and iterate over.

    nums = [1,2,3]\nnums.append(4)\nfor n in nums:\n    print(n)

  7. Dictionaries

    Key/value storage for fast lookups; use .get to avoid KeyErrors.

    person = {"name":"Ada","role":"dev"}\nprint(person["name"])
